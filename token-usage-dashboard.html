ccusage가 뽑아준 JSON을 올리면 어디에 얼마나 썼는지 분석해 드립니다 · 파일 하나로 완결, 인터넷 불필요

① 터미널에서 사용량 데이터 뽑기

아래 명령어 중 하나를 터미널에 붙여넣어 실행하면 usage.json 파일이 만들어져요.
npx ccusage@latest daily --json > usage.json
npx ccusage@latest session --json > usage.json
npx ccusage@latest monthly --json > usage.json
daily(날짜별) · session(프로젝트별) · monthly(월별) — 셋 다 이 대시보드에서 열립니다.
