# 효주 견적 보조 도구 모음

레이저 견적 도우미(`hyoju-quote-v5.html`)를 보완하는 브라우저 도구들입니다.
모두 **설치·인터넷 불필요** — 파일을 더블클릭하면 브라우저(엣지)에서 바로 실행됩니다.

## ⚠️ 데이터 주의

`효주_실적조회.html`에는 **거래처 실명과 실제 견적금액**이, `효주_GEO견적.html`에는
**재질·두께별 단가 통계**가 파일 안에 내장되어 있습니다. (기존 `hyoju-quote-v5.html`도
동일하게 실거래 이력을 내장) **이 저장소는 비공개(private)로 유지하는 것을 권장합니다.**

## 도구 설명

| 파일 | 하는 일 |
|---|---|
| **효주_견적대조.html** | 견적서 PDF 폴더를 고르면 폴더 날짜 ↔ 견적서 날짜 **일치 검증** + 자재/가공/합계 **자동 추출** → 엑셀(CSV)·JSON 저장. pdf.js 내장. |
| **효주_실적조회.html** | 과거 실견적 검색. "대연 SS 3.2"처럼 치면 지난 실제 견적(자재·가공·합계)과 중앙값·범위를 즉시 표시. |
| **효주_GEO견적.html** | GEO 파일 여러 개를 한 번에 올리면 형상(절단·절곡·구멍·중량) 자동 계산 + 대략 견적 + 과거 실적 대조. |
| **효주_견적대조.py** | 위 견적대조와 동일 기능의 파이썬판(Python 3 + `pip install pdfplumber` 필요). `O:\` 전체를 한 번에 훑을 때 사용. |

## 견적 로직 메모 (검증된 사실)

- **소형·박판 부품은 자재비가 무의미**하고 가공·수량이 값을 결정 → 자재비×배수 모델은
  같은 재질·두께에서 배수가 1배~수천 배까지 벌어짐(수량이 지배 변수).
- **자재/가공 분리 금액은 계산식이 아니라 사장님 경험치**(대략 반반, 반올림)로 잡히는 경향.
- 따라서 GEO 자동견적의 목표는 **"형상은 정확히 자동 + 금액은 과거 실적 대조로 사장님이 판단"**.

### 캘리브레이션 앵커

| 건 | 형상 | 실제 견적 | 올인 단가 |
|---|---|---|---|
| 대연하이텍 RUN IN TROUGH ss 3.2t (10EA) | 절단 9,611mm · 절곡 10 · 구멍 34 | 자재 346,000 + 가공 340,000 = **686,000** | **≈ 71원/mm** (소량 단발) |

> 앵커가 1건뿐이므로 `효주_GEO견적.html`의 금액은 **참고치**. 견적 건마다
> (GEO + 수량 + 최종금액)을 추가하면 재질·두께·수량대별로 원/mm를 보정할 수 있습니다.
